**已完成部分的验收**：表单 → IPC → SQLite → safeStorage → 网关热替换 → 列表刷新 全链路无 mock；迁移回滚与幂等有测试；数据库里查不到密钥。证据见 `docs/release/phase-reports/phase-3.md`。

**验收**：UI 上的每个控件都能改变真实状态；关掉应用网关随之停止。

## 已知技术债（按优先级）

| 优先级 | 债务                                | 影响                          |
| ------ | ----------------------------------- | ----------------------------- |
| P1     | 供应商 URL 未做连接时 DNS 固定      | DNS rebinding 未完全阻断      |
| P1     | 无持久化，重启丢失供应商配置        | 目前只能靠配置文件            |
| P2     | 流式背压只做了 `write()` 返回值检查 | 慢客户端可能导致内存增长      |
| P2     | 无重试逻辑                          | 上游偶发 5xx 直接失败给客户端 |
| P3     | 无 i18n                             | 界面文案只有中文              |
